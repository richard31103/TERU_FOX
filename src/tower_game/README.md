# TERU Tower Game (Phase-based)

This folder contains the React + Tailwind source for the tower mini-game.

## Commands

```bash
npm install
npm run dev
npm run build
```

`npm run build` writes the fixed bundle files to:

- `assets/minigames/tower/tower-game.bundle.js`
- `assets/minigames/tower/tower-game.css`

The main game loads these files through `src/js/minigames/tower_bridge.js`.
